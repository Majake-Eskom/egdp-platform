# EGDP Release V1

## Release Date

18-Nov-2026

---

## Overview

EGDP (Eskom Green Data Platform) Version 1 establishes a metadata-driven platform for customer and engagement management.

The platform currently supports:

- Customer Information
- Engagement Tracking
- Gold Data Products
- Data Quality Validation
- Data Publishing
